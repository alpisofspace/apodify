CUSTOMIZATION (if needed)
═════════════════════════════════════════════════════════════════

Change wallpaper style:
  Edit: installer\apodwp_launcher.bat
  Find: set "STYLE=fill"
  Change to: fill, fit, stretch, tile, center, or span

Change installer branding:
  Edit: installer\apodwp_installer.iss
  Find: #define MyAppPublisher
  Change: "Your Name or Company"

Add custom icon:
  1. Create 256x256 .ico file
  2. Save as apodwallpaper.ico in project root
  3. Edit build\apodwp.spec, add: icon='../apodwallpaper.ico'
  4. Rebuild


TROUBLESHOOTING
═════════════════════════════════════════════════════════════════

"ISCC.exe not found"
  → Install Inno Setup 6: https://jrsoftware.org/isinfo.php

"ModuleNotFoundError: rich"
  → Run: pip install rich

"Permission denied"
  → Open PowerShell as Administrator

Build seems to hang
  → Press Ctrl+C and check dist\APODWallpaper\ for output files
